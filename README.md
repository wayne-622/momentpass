# 瞬传 · Vercel 部署说明（免实名 · 免服务器）

本目录是可直接部署到 **Vercel** 的完整项目：

- 在线直连：WebRTC P2P，文件不过任何服务器（逻辑不变）
- 离线投递：文件分片**直传 Vercel Blob 云存储**，发送端关闭页面后接收端仍可凭码取件
- **不需要腾讯云 / 不需要实名认证 / 不需要自己的服务器**：Vercel 用邮箱或 GitHub 账号注册即可，无实名流程

## 目录结构

```
vercel/
├── index.html                              前端页面（自包含单文件）
├── package.json                            声明边缘函数依赖（@vercel/blob）
├── vercel.json                             函数最长执行 60 秒
└── api/relay/[[...path]].js                Vercel 函数：全部离线投递 API（catch-all 单文件）
```

## 部署步骤（约 10 分钟）

### 第 1 步：注册 Vercel（免实名）

打开 https://vercel.com → **Sign Up** → 用 **GitHub 账号**或**邮箱**注册（只需邮箱验证，不需要手机号、不需要实名认证）。

### 第 2 步：把代码推到 GitHub 仓库

把本 `vercel/` 目录里的 **4 个文件/文件夹**（`index.html`、`api/`、`package.json`、`vercel.json`）放到一个 GitHub 仓库根目录（没有 GitHub 账号就先注册一个，同样免实名）。

### 第 3 步：Vercel 导入并部署

1. Vercel 控制台 → **Add New → Project** → 选择刚推的仓库 → **Import**
2. Framework Preset 选择 **Other**，其余保持默认 → **Deploy**
3. 等待 1-2 分钟，成功后得到地址，形如 `https://shunchuan-xxxx.vercel.app`

### 第 4 步（必做）：创建 Blob 存储

离线投递依赖 Vercel Blob，**必须在控制台手动创建并绑定**：

1. Vercel 控制台 → **Storage → Create Database** → 选择 **Blob**
2. 给存储命名（如 `shunchuan-blob`），选择刚部署的项目 → **Create**
3. Vercel 会自动把 `BLOB_READ_WRITE_TOKEN` 环境变量注入项目
4. 回到项目页 → **Redeploy**（重新部署一次，让函数读到新环境变量）
5. 打开 `https://你的项目地址.vercel.app/api/relay/ping`，看到 `{"ok":true,...}` 即部署成功

> 若第 4 步没做，离线投递会报错（函数拿不到存储令牌）；在线直连 P2P 不受影响。

### 更新代码

改完代码重新 push 到 GitHub，Vercel 自动重新部署；或在本地用 `vercel --prod` 手动部署。

## 使用流程

**离线投递（发送端可关页面）：**

1. 打开部署后的网站，选文件 / 文件夹，点「**离线投递**」
2. 文件自动切成 20MB 分片，经签名令牌**直传 Vercel Blob**（字节不经过函数，速度快）
3. 出现分享码后可**关闭浏览器、关机**
4. 接收端打开同一网站输码：先试 P2P 直连，连不上自动从云端流式下载；多文件可一键打包 ZIP（保留文件夹结构、中文文件名）；单文件由浏览器**直连分片 URL 流式下载**（桌面端大文件自动写盘，不占页面内存）

**在线直连（两端同时在线）：** 与之前完全一致，点「生成分享码」，文件点对点直传。

## 国内访问说明（重要）

- `*.vercel.app` 域名在国内**总体可用**，但个别地区/时段可能较慢或被解析干扰。若你或接收方打不开：
  1. **换网络**：手机切 4G/5G 试试（往往比宽带直连更稳）；
  2. **绑定自己的域名**：Vercel 项目 → Settings → Domains 添加域名（国内访问走 Vercel 全球边缘，多数地区可直连；域名不需要备案也能用）；
  3. 备选平台：本目录代码同样可平移到 **Netlify**（netlify.app + Netlify Blobs，同样邮箱注册免实名），需要时告诉我。
- 数据安全：分享码即取件凭证（8 位，约万亿种组合），请通过可信渠道告知对方；本方案无账号体系，个人自用请勿把部署地址公开给陌生人。

## 常见问题

- **点「离线投递」提示无法连接服务**：确认是通过 `https://xxx.vercel.app` 部署地址访问的；直接双击 `index.html`（file://）打开时离线投递不可用（在线直连仍可用）。
- **离线投递报「缺少存储令牌」类错误**：第 4 步 Blob 存储没绑定或没重新部署。
- **接收端一直转圈后提示无包裹**：确认分享码正确、包裹未过期（24h）、发送端当时看到「已暂存云端」。
- **为什么选 Vercel**：国际平台邮箱注册即可，无实名、无手机号绑定、免费版不会扣费，适合个人工具。
- **容量不够怎么办**：升级 Vercel Pro（按量计费但需绑卡，谨慎），或用回 Node 自建版（`server.js`，需常开电脑，无 1GB 限制）。
- **信令/连接问题**：在线直连默认使用公共 PeerJS 信令云，仅交换握手信息；可在右上角「服务器设置」改自建 PeerServer / ICE 配置。
